# Provided challenge source

Original attachment: `ErrorCorrectionChallenge(1).pdf`.

`challenge.pdf` is a byte-for-byte copy, eight pages. `challenge-extracted.txt` contains all eight pages of extracted text. `challenge-sha256.txt` fingerprints the supplied bytes under the repository filename.

From this directory, verify with:

```bash
sha256sum -c challenge-sha256.txt
```

The PDF is retained for reproducibility under the user's provided source; the project does not relicense its contents.
